# Evidence and interpretation

The directory document ID identifies a digital record, not automatically a unique physical object. Response grouping titles are not identity keys: different IDs can share a label. Records are joined by source document ID and retain both catalog labels and internal headings. Identity discrepancies are reported, never silently repaired.

Sentence fields are preserved verbatim, including uncertainty and segmentation. Empty sentences and heading rows remain in raw evidence; only nonempty sentence strings become reference lines. Raw morphology, personal-name identification and linguistic interpretations remain eDiAna assertions rather than project-verified facts. Source rows point into the pinned JSON response using JSON pointers.

No automatic Unicode normalization, translation, token-frequency interpretation, linguistic assignment adjudication or phonetic transfer is applied. A data-label match is not evidence of linguistic relationship. Different editions, object surfaces and witness dependence require an explicit comparability gate.

Coverage reports distinguish directory document IDs, response grouping titles, acquired document IDs, nonempty source lines and independently verified objects. Full coverage means full coverage of this captured directory, not completeness of the surviving language corpus. The declared source version may be archival.

Next work: reconcile object/edition identities, locate publication pages, inspect primary editions and images under their own rights, preserve edition disagreements, and obtain independent review. These are tracked gates, not reasons to inflate a release version.
